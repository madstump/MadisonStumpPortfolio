# Madison Stump Portfolio Website

This is a ready-to-edit multi-page HTML/CSS/JavaScript portfolio site with an evergreen forest theme.

## Files included

- `index.html` — Home page with intro, skill sections, portfolio paths, and current projects.
- `resume.html` — Detailed résumé page based on the included résumé PDF.
- `curriculum.html` — Teaching/curriculum page with courses, classroom systems, artifacts, and robotics section.
- `projects.html` — Filterable project library for teaching, coding, game design, media, writing, and hobbies.
- `showcase.html` — Embed library for Google Slides, Google Docs, videos, images, downloads, and contact info.
- `styles.css` — Full forest-themed styling.
- `script.js` — Navigation, progress bar, scroll reveal, project filters, copy email button, and back-to-top button.
- `assets/` — Placeholder forest graphics, project placeholders, embed placeholders, and favicon.
- `docs/` — Included résumé PDF.

## How to edit

1. Open the folder in VS Code or your preferred editor.
2. Replace placeholder images in `assets/` with your own images. Keep the same filenames if you do not want to update the HTML.
3. Replace `href="#"` links with real links to your projects, Docs, Slides, videos, GitHub, or Canva pages.
4. To embed Google Slides, Docs, or YouTube videos, replace the placeholder image block in `showcase.html` with the iframe embed code.

## Google embed tips

### Google Slides
File → Share → Publish to web → Embed → copy iframe code.

### Google Docs
File → Share → Publish to web → Embed → copy iframe code.

### YouTube
Share → Embed → copy iframe code.
